# Coudre avec la LS-1217

Guide interactif pas à pas pour débuter sur la machine à coudre **Brother LS-1217** : réglages, bobinage, canette, enfilage, première couture et dépannage.

Web app installable (PWA) : ouvre le lien sur ton téléphone puis « Ajouter à l'écran d'accueil ». Fonctionne hors-ligne après la première visite.
